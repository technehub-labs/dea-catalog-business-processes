Verification that the target never existed: no `entities/v1-alpha/dea:process-frame-financial-policy-thesis/` record in any commit (`git log --all`), no register v2 entry (CR-BP-19), no row in the CR-BP-21e landing table (only `dea:process-frame-finance-strategy` for FA/Conceive), no `docs/examples/frame-financial-policy-thesis.md` evidence file in any commit. The edge was born dangling at CR-BP-21e (2026-09-08).

With the gate repaired and the edge removed, the live PG gate scans all 35 ProcessGroup records against 126 canonical BP ids and passes PG-001..008 with 0 errors and 0 suggestions.

**Version posture**: the PG record keeps version 1.0.0. The removed edge carried no resolvable semantics (target never existed in register or catalog); the record's declared identity (definition, scope, coordinate) is untouched, so SIV-004 keeps the version unchanged.
