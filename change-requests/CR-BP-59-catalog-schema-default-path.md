## 1. Change Request

Repair `DEFAULT_SCHEMA_PATH` in `scripts/regenerate_catalog.py` and `scripts/check_catalog_index.py`: `tools/catalog-index-schema.json` -> `catalog-index-schema/catalog-index-schema.json`.

The `tools/catalog-index-schema.json` path has never existed in this repository; the schema has lived at `catalog-index-schema/catalog-index-schema.json` since the layout was established. The stale default made both scripts fail on bare invocation (`python scripts/regenerate_catalog.py` without `--schema`), and every working invocation in tests and CI already passes `--schema catalog-index-schema/catalog-index-schema.json` explicitly. This change aligns the defaults with the only invocation form that has ever worked.

## 2. Mechanics

1. One-line constant change in each of the two scripts (the `--schema` argparse default references the constant, so help text updates automatically).
2. No caller changes required: CI (`.github/workflows/ci.yml` lines 89, 93) and the test suite pass `--schema` explicitly; explicit arguments override defaults.
3. Reconciliation artifacts regenerated; record counts unchanged (697, all L4).
