## 1. Change Request

Land the **decomposition semantic contract** at `docs/decomposition-semantic-contract.md` as the authoritative normative prose for the L0-L4 decomposition chain. Establish six normative layers (Process Context, L0 Process Scope, L1 Process Group, L2 Business Process, L3 Activity, L4 Task), each with:

* Question it answers;
* Normative definition;
* Allowed / disallowed semantic interpretations;
* Where the contract lives today (canonical records, schema, gate, reader-facing prose);
* Cross-references to the existing gate families.

Plus three cross-cutting sections:

* The decomposition-vs-execution separation (Process Architecture L0..L4 vs Execution Realization L4 -> Workflow -> Instance -> Execution).
* The level-specific information-requirements matrix (restated from CR-BP-92 §5).
* The universal decomposition-element contract (restated from CR-BP-92 §4).
* The glossary reconciliation (the authoritative decomposition-half vocabulary).
* The allowed/disallowed semantic-interpretation table.
