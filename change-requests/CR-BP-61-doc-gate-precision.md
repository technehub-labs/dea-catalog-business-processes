## 1. Change Request

Repair the evaluation granularity of DOC-001 and DOC-003 in `scripts/check_documentation_conformance.py`. The rules evaluated hard-wrapped markdown per line, producing systematic false positives:

1. **Wrap artifacts**: a sentence split across lines ("... Business / Process.") fired DOC-003 on the continuation line; multi-line distinction sentences ("Process Group is NOT / equivalent to Business Function, ...") fired DOC-001 because the preferred term sat on a different line.
2. **Fenced code blocks and inline code spans**: literal tokens that must appear verbatim (schema discriminators like `process-kernel`, field names like `decomposition_boundary`) fired both rules.
3. **ATX headings**: concept names ("## Decomposition", "# Process Classification") fired both rules.
4. **Table rows**: canonical taxonomy labels (the `classifications/process-types.yaml` vocabulary names "Strategic Process", "Management Process", etc.) fired DOC-003.
5. **Case/hyphen variants**: "Process kernel", "Process-specialization" missed the case-sensitive, space-only compound allowlist.

Mechanics (checker-only; no rule-contract change):

- New `_prose_blocks` evaluator: hard-wrapped lines join into blocks (blank line ends a block; list items join the enclosing block so an intro line's preferred term covers its items); fenced code, ATX headings, and table rows are excluded.
- Inline code spans stripped before matching.
- DOC-001: preferred-term presence evaluated per block (was per line); legacy/formerly/deprecated qualifier window unchanged.
- DOC-003: compound matching is case-insensitive over whitespace/hyphen-normalized text; allowlist extended with grounded catalog vocabulary (`Process Scope`, `Process Classification`, `Process Contribution`, `Process Decomposition`, `Process Landscape`, `Process Discipline`, and the five `process-types.yaml` category names).
- DOC-002 and DOC-004 untouched.

**No documentation content changes.** A full manual audit of every living-doc residual finding (41) found zero true positives.

## 3. Residual findings: classification (audited, all 41 living-doc residuals)

- **The 'Decomposition' class** (majority): blocks using the catalog's own L0-L4 architectural concept without the word "Specialization" nearby. Whether unqualified "decomposition" usage for the hierarchy violates S22 is a **rule-contract interpretation question** (LEGACY_TERMS maps Decomposition -> Specialization with the note "Decomposition is a different relationship"). Not redefined here; surfaced for governance.
- **Proper-noun / block-join artifacts** (a few): CR titles ("Process Semantic Reconciliation"), a block-joined enumeration item. Accepted noise.
- **Historical documents** (`change-requests/`, `01_plan/`, `CHANGELOG.md`; 191 of the 232 repo-wide residuals): era-accurate terminology in immutable records. Rewriting history is rejected by design; whether the gate should exclude historical directories is a coverage decision left open (see NOT-list).
