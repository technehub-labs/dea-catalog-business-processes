## 1. In a Nutshell (provided)

This is a **Activity** (level L3), named **Configure Line Controls**, currently **candidate (yellow)**. It is part of the **Operations and Enablement Build** process context, domain `eo`, lifecycle stage Build. It belongs to **Commission Production Line** (`processes:process-eo-build-awy8dz`). Its canonical ID is `processes:activity-eo-build-tqqyb8`.

This activity sets the line's automation, quality checks, and safety cut-outs to the parameters the design specifies. The installed line arrives with the operations model design as the reference, each control is configured and its settings verified, and the configured controls are confirmed onward. The line now knows how fast to run, what to reject, and when to stop.

## 2. Why It Matters (provided)

It exists so the line runs within its designed operating parameters from the first powered turn, with quality and safety wired in.

## 3. Where You'd Encounter It (provided)

It follows equipment installation, when the assembled line is presented for configuration, and it completes once the configured controls are confirmed for trials.

## 4. Worked Example (provided)

*Example (carried out by a person):* A processing custodian sets the line's automation, quality gates, and safety cut-outs to the design's parameters, verifies each setting, and confirms the configured controls for trial running.
