## 1. In a Nutshell (provided)

This is a **Activity** (level L3), named **Evaluate Programme Effectiveness**, currently **candidate (yellow)**. It is part of the **Agent Operations and Performance** process context, domain `ao`, lifecycle stage Operate. It belongs to **Operate Learning and Development** (`processes:process-ao-operate-87q5mk`). Its canonical ID is `processes:activity-ao-operate-8mxujq`.

This activity weighs each finished programme against the shortfalls it was meant to close. The recorded completions come in as the starting evidence, effectiveness is judged programme by programme, and the evaluation is confirmed and retained. Which programmes genuinely closed their gaps becomes visible, and which did not.

## 2. Why It Matters (provided)

It exists so the enterprise learns which development programmes actually close the shortfalls they target.

## 3. Where You'd Encounter It (provided)

It runs once programmes have completed and their completions are on file, and it closes when the effectiveness evaluation is confirmed and its record retained.

## 4. Worked Example (provided)

*Example (carried out by a person):* A processing custodian compares each finished programme's outcomes with the gap it targeted, records how far the shortfall actually closed, and confirms the evaluation for the record.
